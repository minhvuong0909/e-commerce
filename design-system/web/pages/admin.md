# Page Override: Admin Hub

> Overrides `design-system/web/MASTER.md` for the Admin & Staff Workspace (`/admin/*`).

---

## Workspace Direction
- **Theme:** High-density, neutral dark slate with warm accents (`#141721` sidebar, `#F7F7F8` work area, `#0F1117` shell).
- **Density:** Compact / high density (spacing 8-16px, table row heights 48px).
- **Typography:** Inter / Plus Jakarta Sans with Monospace tabular figures for IDs, metrics, currency, order codes.
- **KPI Indicators:** Emerald for revenue growth, Amber for pending tasks, Rose for stock alerts.
